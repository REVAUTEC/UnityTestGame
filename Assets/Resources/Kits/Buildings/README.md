# Buildings – budovy (napojím později)

Sem nahraj modely budov (kancelář, garáž/servis, ploty, brána…) – `.fbx`/`.obj`/`.gltf`.

Zatím je svět postavený z kostek. Až sem nahraješ modely a napíšeš mi, napojím je
(podobně jako auta: auto-fit + záloha na kostky).

Tip na zdarma balíčky: **Kenney – City Kit (Commercial)**, **Survival Kit**, **Graveyard Kit**.
